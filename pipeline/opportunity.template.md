# Opportunity: [solicitation number]

One file per opportunity you are tracking. Copy this template to `pipeline/<solicitation-number>.md`, replacing any character that is illegal in a filename with a dash. The `/find-opps` job creates these for you; the `/bid-no-bid`, `/teaming`, and `/submit-package` jobs read and update them.

Every field here comes from the notice or the solicitation. If a field is not stated in what you have, write "not stated" rather than a guess, and ask the contracting officer if it matters.
